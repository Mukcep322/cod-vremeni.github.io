# Улицы в военное время

Мобильный одностраничник для пешего квеста по центру Липецка: 6 мест на 5 остановках, ≈ 2,7 км, около 1,5 часа.
React 18 + TypeScript + Vite, карта — Яндекс Карты JavaScript API 3.0.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в папку dist/
npm run preview    # посмотреть собранную версию
```

Геолокация работает только по HTTPS или на `localhost`. Чтобы проверить её с телефона в одной Wi‑Fi‑сети, запустите `npm run dev -- --host` и откройте адрес из консоли, либо проверяйте уже на GitHub Pages.

## Что заполнить

| Что | Где |
|---|---|
| Ключ Яндекс Карт | скопируйте `.env.example` в `.env` и впишите `VITE_YMAPS_API_KEY` |
| Тексты, задания, ответы, подсказки | `src/data/stops.ts` — перенесено из таблицы команды; чего в ней нет, отмечено на сайте пометкой «Нет данных» (вызовы `noData(...)`) |
| Фото «тогда / сейчас» | файлы в `public/photos/`, пути в полях `then` и `now` в `src/data/stops.ts` |
| Аудиолегенды | файлы в `public/audio/`, путь в поле `audio`, длительность в `audioDuration` |
| Фото в финале | `public/photos/`, путь в `FINAL_PHOTO` в `src/screens/Finish.tsx` |
| Вступление и финальный факт | `INTRO` и `FINAL_FACT` в `src/data/stops.ts` |

Пути пишутся без ведущего слэша: `photos/stop-1-then.webp`, `audio/stop-1.mp3`. Пустая строка показывает заглушку.

В заданиях, которых нет в таблице (`NO_TASK`), временный правильный ответ — слово `ответ`. Замените их настоящими заданиями. Ответ сравнивается без учёта регистра, пробелов, знаков препинания и разницы «ё/е».

Пока ключа нет, вместо карты Яндекса рисуется схема маршрута по тем же координатам — сайт полностью проходится и без ключа.

## Как устроено

```
src/
  data/stops.ts          остановки, истории, задания, источники
  lib/ymaps.ts           загрузка JS API 3.0 и @yandex/ymaps3-reactify
  lib/geo.ts             расстояния, радиус «на месте» (50 м), ссылка на маршрут
  hooks/useGeolocation   слежение за положением
  state/progress.tsx     прогресс в localStorage
  components/            карта, схема-заглушка, шторка «тогда/сейчас», аудиоплеер
  screens/               Start, Walk, Stop, Done, Finish
```

Экраны совпадают с макетом в Figma (стиль «Спираль времени», токены — в начале `src/styles.css`):

1. `#/` — старт и окно «Продолжить маршрут?» при повторном открытии
2. `#/walk` — карта, «я здесь», шторка со следующей остановкой. В 50 м от точки экран точки открывается сам
3. `#/stop/:id` — тогда/сейчас, аудиолегенда, текст, задание. На остановке 3 две вкладки, задание открывается после обеих
4. `#/stop/:id/done` — ответ принят
5. `#/finish` — итог, имя с плиты, источники, «Поделиться»

После трёх неверных ответов показывается правильный и можно идти дальше.

## Ключ Яндекс Карт

1. Получите бесплатный ключ JavaScript API в кабинете разработчика Яндекса.
2. В настройках ключа ограничьте его адресом сайта (например, `ваш-логин.github.io`) и `localhost` — ключ виден в коде страницы.
3. Условия бесплатного использования требуют, чтобы сайт был открыт всем и не скрывал логотип, копирайты и кнопку «Открыть в Картах». Шторки в вёрстке занимают нижнюю часть экрана — проверьте, что логотип остаётся виден.

Для строгих типов API можно поставить `npm i -D @yandex/ymaps3-types` и подключить их по инструкции Яндекса; сейчас компоненты карты типизированы как `any` в `src/lib/ymaps.ts`.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите проект в ветку `main`.
2. Settings → Pages → Source: **GitHub Actions**.
3. Settings → Secrets and variables → Actions → New repository secret: `YMAPS_API_KEY` с вашим ключом.
4. Каждый push в `main` собирает и публикует сайт (`.github/workflows/deploy.yml`).

Адрес сайта: `https://<логин>.github.io/<репозиторий>/`.

Если на сайте белый экран или текст «Загружаем маршрут…», откройте код страницы. Строка `<script type="module" src="/src/main.tsx">` значит, что Pages публикует исходники из ветки, а не сборку: проверьте пункт 2 и запустите workflow заново.
